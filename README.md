# coLearn-AI Information

The public information site for [coLearn-AI](https://github.com/jimskon/coLearn-AI): a collaborative, AI-assisted learning platform built around visible reasoning, purposeful group work, and instructor insight.

## Publish with GitHub Pages

This repository is dependency-free. In the repository's **Settings → Pages**, choose **Deploy from a branch**, select `main`, and use the repository root (`/`). GitHub Pages will publish `index.html` directly.

The site includes platform information, group activities, tests and quizzes, assignments and labs, the demo/playground, and instructor workflows.

## Local preview

```sh
python3 -m http.server 4173
```

Then open <http://localhost:4173>.
